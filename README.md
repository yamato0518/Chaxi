作品名「chaxi」

開発環境　Unity　
使用言語　C# 
制作期間　3ヶ月
制作人数　４人

作品概要
大学の講義の課題として特殊コントローラーを用いたゲームを開発しました。茶道で使う茶筅と茶碗をコントローラーとして操作するランゲームです。
ゲーム全体のプログラムを担当しました。

SerialHandler,SerialReciveのコントローラーからの値を受け取る処理と、ShaderOpeningManagerのシェーダーの処理の作成にGithub CopilotとGoogle Geminiを使用しています。


コード全体のデバッグ、最適化にGithub CopilotとGoogle Geminiを使用しています。
